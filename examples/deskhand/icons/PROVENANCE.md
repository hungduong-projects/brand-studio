# Deskhand icons provenance

Deskhand is a fictional product. The glyphs and app icon layers are original Brand Studio work.

- `glyphs/*.svg`: hand-written for this example on Lucide's 24 px grid at Deskhand's 1.8 px stroke. Lucide's design rules are followed; no Lucide paths are copied.
- `app/*.svg`: the Deskhand mark, traced from the existing app icon, as Icon Composer layers.
- `out/`: exported with `plugins/brand-studio/skills/brand-design/scripts/icons.mjs`. Source type `code` (IPTC `algorithmicMedia`).
- `examples/deskhand/mobile/assets/icon.png`, `android-icon-foreground.png`, `android-icon-monochrome.png` and `favicon.png` are copies of these exports.
