## Usage

```tsx
import { CurtainReveal } from '@brand-studio/ui';
```

```tsx
<CurtainReveal>
  <div>It starts with the bean.</div>
  <div>Roasted every Monday.</div>
  <div>Yours by Friday.</div>
</CurtainReveal>
```

Each child becomes a panel at least one screen tall. Give each its own background so the one underneath is hidden.

## Accessibility

- Every panel is a section in reading order; nothing is hidden or reordered.
- Without scripts, and under reduced motion, the panels still stack but nothing sinks or dims.
