## Examples

### Sizes

`size` sets the orb's width in pixels. Below 64 pixels it draws fewer dots so it stays crisp next to text.

<Preview name="agent-thinking/sizes" />

## Accessibility

- The component has `role="status"`. With `label` it shows and announces that text; without it, screen readers hear the state name.
- Each state has its own shape and motion, so it does not rely on colour alone. The orb pauses off screen. Under reduced motion the dots hold still and the label stays.
