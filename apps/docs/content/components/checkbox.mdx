```tsx

```

## Accessibility

- Renders a native `<button role="checkbox">` with a real `<label>`. Space toggles it.
- `indeterminate` sets `aria-checked="mixed"` for a parent box whose group is partly ticked.
- `description` is linked with `aria-describedby`.
