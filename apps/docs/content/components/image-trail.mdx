## Usage

```tsx
import { ImageTrail } from '@brand-studio/ui';
```

```tsx
<ImageTrail images={images}>
  <h2>Move your mouse here.</h2>
</ImageTrail>
```

## Accessibility

- Decorative only: trail images have empty alt text.
- Touch and reduced motion show only the content.
