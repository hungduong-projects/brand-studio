## Usage

```tsx
import { VoiceOrb } from '@brand-studio/ui';
```

```tsx
<VoiceOrb state="listening" level={level} size={140} />
```

`level` runs from 0 to 1. Feed it the microphone's loudness while listening (DictationButton's `onLevel` gives you this) or the agent's voice while speaking. Idle shows a ring that breathes, listening sends a wave through rows of dots, thinking runs dots round tilted orbits and speaking spreads ripples from the orb's face. The dots take the ink colour, so the orb follows light and dark themes. Below 64 px it draws fewer, larger dots.

## Accessibility

- The orb is a status that says its state in words: Ready, Listening, Thinking or Speaking. `label` shows your own words instead.
- The drawing is hidden from screen readers.
- With reduced motion the orb holds still but still follows the level. It also stops drawing when it scrolls off screen.
